# Hat Shop artwork

Copied from Commie's existing Hat Shop (`wolt/site/tryon/img` and `assets.json`) for the owner-approved Shell Phone contact-card design, November 12 2026. CardLook uses the same creature-specific hat anchors, glasses placements and scene palettes as the approved mock renderer. These assets are imported through Vite so built URLs work with the existing static asset server.

The look changes presentation in this room; choosing a creature here does not change the wolt's underlying model or lodge creature configuration.
